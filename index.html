Built apart, they don't combine.

Products are islands. Each has its own login, its own data and its own interface.

Same data, their own calculation. Each product pulls the same records and computes the number itself. The definitions differ slightly: who counts as a learner, which dates, what counts as done.

Small differences compound. Each definition changes a little on its own, so the numbers drift apart over time, and no one can say which one is right.

Define it once. Same number everywhere.

Define it once. In the semantic layer, a metric is written as code, in one place. One definition for everyone.

Expose it twice. An API for product screens, an MCP (Model Context Protocol) server for AI. The same definition sits behind both.

AIA (AI and Analytics) owns the gateway. It checks who is asking and what they may see, and logs everything. Every surface shows the same number.
