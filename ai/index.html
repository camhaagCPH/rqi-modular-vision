AI in RQI

Built by many teams.
Designed to fit together.

Services built by different teams can each include AI. Brought together, those features can end up on the same screen or in the same conversation. Streamlined design keeps them from clashing.

AI is part of
the capability.

A capability already ships an API, an MCP server and a component. Its AI is the next extension of it: the tools an assistant can call, and the patterns that decide how AI shows up. Samaritan AI is the shared identity every extension builds on.

APIMCP serverComponentAI extension

Why it matters.

For the person using it, patterns mean learning AI once. For the platform, they mean features that were never designed together can still live together.

a chatbot.

A report the AI has no tools to work on is a final delivery, not a conversation. Defining each level is something AIA needs to do. The examples below are wireframes from our own exploration, not final patterns or rules.
